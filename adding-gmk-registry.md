# Adding GM Kitchen Registry

1. Please add `https://gmpm.gamemakerkitchen.com/` as a package source via the package manager. 

Optionally with the name `GameMaker Kitchen` and Install Subdirectory as `GMK`.

![Tools, package manager](/Graphics/access-package-manager.png)

![Add source Pt 1](/Graphics/add-source.png)

![Add source Pt 2](/Graphics/package-manager-source.png)

2. Switch to the registry.

![Switch to source](/Graphics/switch-to-regsitry.png)

From here, you can test all of the prefabs that the GameMaker Kitchen registry has.

3. After installing any prefabs, you can head over to the prefab library menu. If a prefab has functions (such as GM Animate or GM Community Toolbox), you can add it as a collection reference.

![Prefab library](/Graphics/prefab-library.png)

![Add collection reference](/Graphics/collection-reference.png)
